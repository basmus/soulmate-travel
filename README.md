# Soulmate Travel

Static landing page for the Soulmate Travel site.

## Overview
This repository contains a simple HTML/CSS site with local image assets.

## Project structure
- `index.html` — main markup
- `styles.css` — site styles
- `images/` — image assets
- `CNAME` — custom domain configuration

## Run locally
Open `index.html` directly in your browser, or serve the folder with any static file server.
